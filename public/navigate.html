How Phase 2 Works

The campus is modelled as a weighted graph. Each building is a vertex. Pathways between buildings are edges with weights = approximate walking distance. Dijkstra’s Algorithm finds the shortest path from source to destination. The path is shown step-by-step and highlighted on the mini map below.
