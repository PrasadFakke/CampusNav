Find Shortest Route

Using Dijkstra's Algorithm on campus graph

Select source and destination, then click Find Shortest Path

How it works

The campus is modelled as a weighted graph. Each building is a vertex. Pathways between buildings are edges with weights = approximate walking distance. Dijkstra's Algorithm finds the shortest path from the source to the destination. This is the core Computer Science concept demonstrated in this mini project.
