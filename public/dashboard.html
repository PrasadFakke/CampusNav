About This Project

This Smart Campus Navigation System models the campus as a weighted graph. Buildings are vertices and pathways are weighted edges (based on distance). The system uses Dijkstra’s Algorithm to find the shortest path between any two locations and supports Floyd-Warshall for all-pairs shortest paths. Users can also get alternative routes when pathways are blocked and find the nearest facilities.
